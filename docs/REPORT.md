# 训练和测试记录

## 数据与方法

使用 scikit-learn 的 `load_digits` 数据集，数字类别为 0–9，每张图是 8×8 灰度图。数据集一共 1797 张。按类别分层划分训练集和测试集，随机种子固定为 42，测试集占 20%。

为了让模型适应画板输入，训练集中的每张图还生成一个经过图片预处理流程的版本。两个版本使用同一标签；测试集中的图片只用来评估。模型是 `StandardScaler` 加 RBF 核 SVM。标准化和分类器放在同一个 Pipeline 里，避免测试集信息进入训练时的标准化过程。SVM 参数为 `C=10`、`gamma="scale"`。

运行 `python digits.py train` 会重新训练模型，把模型保存为 `model.joblib`，并把准确率、分类报告和混淆矩阵写入 `metrics.json`。这次运行在 360 张原始测试图上的准确率为 97.22%，同一批图片经过画板预处理后的准确率为 98.89%。

## 使用自己的图片

画板和命令行预测都会先把输入图转换成灰度图，必要时反转颜色，再截取数字区域、放到正方形画布中央，缩小到 8×8。这个处理能让普通图片接近训练集的形状，但不能保证笔画风格一致。尤其是数字太细、背景有纹理或一张图里有多个数字时，结果可能不稳定。

## 测试

`python -m unittest -v` 检查训练后是否生成模型、测试集准确率是否达到 0.95，以及空白图片是否被拒绝。它是代码回归检查，不代替独立的实拍评估。

如果继续做课程实验，可以另外收集自己写的数字，记录每个数字的识别正确率，并分析容易混淆的类别。要避免把这些新增图片同时用于调参和最终评估。
