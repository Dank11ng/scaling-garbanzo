# 实现和测试记录

## 处理流程

这个项目把文档扫描拆成三步：找纸张边框、透视校正、黑白化。实现集中在 `scanner.py`，没有使用训练模型。

边框检测使用缩小后的图像，避免大照片带来过多计算；校正仍使用原图，以保留文字细节。Canny 提取边缘后，用闭运算连接间隙，再通过轮廓近似寻找四边形。

当前选择的是面积最大的合格四边形。这种方法实现简单，但没有判断“这个区域是不是纸张”，所以遇到复杂背景时可能选错。

## 透视校正

四个角点先按绕中心的角度排序，再以坐标和最小的点作为起点。校正后的宽高取两组对边中较长的一条，不会自动恢复纸张原本的长宽比。

透视变换满足 `s[x', y', 1]^T = H[x, y, 1]^T`。矩阵 H 去掉整体尺度后有 8 个自由度，可以用四对对应点求解。这里用 `cv2.getPerspectiveTransform` 计算矩阵，再用 `cv2.warpPerspective` 生成校正图。

黑白化使用高斯自适应阈值，根据局部亮度计算阈值。轻微的光照不均可以通过这种方式处理，但强阴影仍然可能影响结果。

## 测试

测试环境：Python 3.12.10、OpenCV 5.0.0、NumPy 2.5.3。

运行 `python -m unittest -v`，4 项测试通过：

| 测试 | 检查内容 |
| --- | --- |
| 合成图检测 | 四个角点与生成坐标的最大距离小于 10 像素；校正图高度大于宽度；黑白图只包含 0 和 255 |
| 角点排序 | 同一四边形的 24 种输入排列得到相同结果 |
| 空白图片 | 找不到文档时抛出异常 |
| 重合角点 | 四个点重合时抛出异常 |

`make_demo.py` 先画一张带文字和图形的纸，再通过已知透视矩阵放到背景上。因为生成时保留了角点坐标，可以检查检测误差。这个测试只能说明程序在该合成样本上按预期运行，还不能说明实拍效果。

## 后续实验

需要补充简单背景、复杂背景、阴影和不同拍摄角度下的实拍照片。可以记录每张图是否选对边框、角点与人工标注的距离，以及处理时间。用于调参的照片和最后统计结果的照片应分开。

参数对比可以先从 Canny 阈值开始：阈值太低会保留背景纹理，太高又容易丢掉纸张边缘。闭运算核和轮廓近似精度也会影响检测，比较时每次只改一个参数。
