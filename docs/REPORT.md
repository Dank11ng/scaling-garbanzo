# 实验记录与答辩提示

## 目标

实现从单张文档照片到正视扫描图的传统计算机视觉处理流程，展示边缘检测、轮廓近似、单应性变换和自适应阈值的配合方式。

## 已完成的验证

运行 `python -m unittest -v`，4 项通过：

| 检查 | 判定标准 |
| --- | --- |
| 合成图自动定位 | 四个预测角点与生成时真实角点的最大欧氏距离小于 10 像素 |
| 透视校正与二值化 | 输出竖向图像，二值图包含且只包含 0 和 255 |
| 角点排序 | 同一四边形全部 24 种输入排列得到相同顺序 |
| 异常处理 | 空白图像和重合角点抛出明确异常 |

表中校正与二值化检查包含在自动定位测试中。合成样本使用已知单应性矩阵生成，因此可以计算角点误差。它是程序正确性验证，不是自然场景识别率评测。

## 建议补充的本科实验

自行拍摄至少 20 张不含个人敏感信息的文档，覆盖简单背景、复杂背景、阴影和不同倾角。对每张图记录是否成功、手工标记的四角坐标与运行时间。不要把调参用图和最终评测用图混在一起。

- 检测成功率：符合预先定义的正确边框标准的图片数 / 总图片数。
- 归一化角点误差：对应角点距离的均值 / 原图对角线长度。
- 处理耗时：固定硬件和图像分辨率后，报告多次运行的中位数。

尚未执行上述实拍评测，因此本项目不报告实拍准确率或泛化性能。

## 参数实验

保持其他设置固定，分别改变 Canny 阈值、闭运算核大小和轮廓近似比例。阈值过低容易引入纹理边缘，过高可能丢失纸张边缘；闭运算过强可能合并无关轮廓；近似精度会影响四边形是否被识别。

## 答辩问题

1. 为什么检测时缩图而变换时使用原图？降低检测成本，同时保留输出细节。
2. 为什么四个对应点可以确定透视矩阵？单应性矩阵去除整体尺度后有 8 个自由度，每对对应点提供两个约束。
3. 为什么选择自适应阈值？它根据局部亮度确定阈值，较适合轻度光照不均，但不能保证去除强阴影。
4. 为什么可能找到桌面而不是纸张？当前策略选择最大合格凸四边形，缺少语义判断。
5. 为什么没有深度学习？任务可以通过可解释的经典算法实现，便于理解几何与图像处理，也降低运行成本。
